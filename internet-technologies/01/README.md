# Практическая работа 1. Как работает веб-приложение

1. **Где в программе хранится состояние?**
   Состояние хранится в переменной `value` (объявлена через `let value = 0;`).

2. **Какая функция обновляет интерфейс?**
   Интерфейс обновляет функция `render()`. Она вызывается после каждого изменения переменной `value`.

3. **Какие события обрабатываются?**
   Обрабатываются события `click` (нажатие) на трёх кнопках: `increase` (+1), `decrease` (-1) и `reset` (Сброс).

4. **Что произойдёт, если изменить значение переменной, но не вызвать функцию обновления интерфейса?**
   Изменения не отобразятся на экране. Пользователь увидит старое значение, хотя в памяти программы число уже изменилось. Интерфейс и данные разойдутся.
