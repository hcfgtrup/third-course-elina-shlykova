# Практическая работа 2. Анализатор чисел

1. **Где хранятся исходные данные?**
   В массиве `values` (`const values = [];`).

2. **Почему показатели лучше вычислять на основе массива, а не хранить отдельно?**
   Потому что массив — это единственный источник правды. Если хранить сумму отдельно, можно случайно изменить массив и забыть обновить сумму. А если вычислять на лету, данные всегда будут согласованы.

3. **Что возвращает `getStatistics()`?**
   Объект с полями: `count` (количество), `sum` (сумма), `average` (среднее), `min` (минимум), `max` (максимум).

4. **Как программа обрабатывает пустой массив?**
   `getStatistics` проверяет `if (arr.length === 0)` и возвращает нули, а для min/max — `null`, чтобы не было `Infinity` или случайных чисел. В интерфейсе вместо `null` выводится прочерк «—».

5. **Какое место в программе было сложнее всего отладить?**
   Самым сложным было правильно обработать пустой массив, чтобы не появлялось `Infinity` при делении на ноль (среднее значение) и чтобы `Math.min()` не возвращал `Infinity`.
