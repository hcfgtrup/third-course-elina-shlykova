# Практическая работа 3. Каталог пользователей из API

1. **Какой endpoint используется?**
   `GET https://jsonplaceholder.typicode.com/users`

2. **Какой HTTP-метод отправляется?**
   GET.

3. **Где в программе хранится состояние?**
   В объекте `state`: `users` — массив, `isLoading` — флаг загрузки, `error` — текст ошибки, `filter` — строка фильтра.

4. **Какие состояния интерфейса предусмотрены?**
   - данные ещё не загружены;
   - идёт загрузка («Загрузка...»);
   - данные успешно получены;
   - произошла ошибка.

5. **Как обрабатывается ошибка?**
   Через `try/catch`. Если `response.ok === false` — выбрасываю `Error` с кодом статуса. Блок `catch` сохраняет текст в `state.error`. В `render()` при наличии ошибки показывается сообщение.

6. **Какие поля участвуют в фильтрации?**
   `name`, `username`, `email`.

7. **Что вы увидели в Network при успешном запросе и при ошибке?**
   Успех: Request URL `https://jsonplaceholder.typicode.com/users`, Method GET, Status 200 OK, Content-Type application/json.
   Ошибка: Status 404 Not Found, в Response — сообщение об ошибке.
