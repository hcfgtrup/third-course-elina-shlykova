# Практическая работа 3. Окружность по пикселям

1. **Как используется симметрия окружности?**
   Если найдена точка `(x, y)`, ей соответствуют ещё семь точек: `(y, x)`, `(-x, y)`, `(-y, x)`, `(x, -y)`, `(y, -x)`, `(-x, -y)`, `(-y, -x)`. Функция `plot8` рисует все восемь точек за один вызов.

2. **Почему достаточно строить одну восьмую?**
   Окружность симметрична относительно осей X, Y и диагоналей. Достаточно вычислить точки в секторе от 0° до 45° (где `x <= y`). Остальные семь восьмых получаются отражением. Это сокращает вычисления в 8 раз.

3. **Что означает переменная `d`?**
   `d` - решающая переменная. Она показывает, с какой стороны от идеальной окружности находится средняя точка между двумя кандидатами на следующий пиксель. Если `d < 0` - средняя точка внутри окружности, выбираем пиксель E (x+1, y). Если `d >= 0` - снаружи, выбираем SE (x+1, y-1).

4. **Когда уменьшается `y`?**
   `y` уменьшается, когда `d >= 0`. Это значит, что средняя точка оказалась снаружи окружности, и нужно сдвинуться вниз, чтобы приблизиться к идеальной линии.

5. **Почему цикл заканчивается при `x > y`?**
   Мы строим только сектор от верхней точки примерно до направления 45°. На границе этого сектора `x = y`. После этого следующие точки - отражение уже построенных. Продолжать вычисления нет смысла.

6. **Совпали ли пиксели алгоритма средней точки и способа через формулу?**
   В большинстве случаев совпадают. Возможны расхождения на 1 пиксель в спорных ситуациях, потому что `Math.round` и решающая переменная по-разному обрабатывают пограничные значения.

7. **Что показал эксперимент по времени?**
   Алгоритм средней точки быстрее, потому что использует только целочисленные операции: сложение, вычитание, умножение на 2 и сравнение. Способ через формулу использует `Math.sqrt` и `Math.round`, которые работают с вещественными числами.
