# Практическая работа 2. Алгоритм Брезенхема

1. **Чем идея Брезенхема отличается от ЦДА?**
   ЦДА использует вещественные приращения (дробные числа) и округление на каждом шаге. Брезенхем использует целочисленную переменную `error` (ошибку), которая накапливается и позволяет выбирать следующий пиксель без деления и округления.

2. **Для чего используется переменная `error`?**
   `error` показывает, насколько мы отклонились от идеальной математической линии. Если ошибка становится слишком большой (положительной или отрицательной), мы корректируем координату.

3. **Зачем нужны `sx` и `sy`?**
   Они показывают направление движения по осям X и Y. `+1` — движение вправо/вниз, `-1` — влево/вверх. Это позволяет алгоритму работать для всех направлений отрезка, а не только слева-направо.

4. **Почему две проверки изменения координат нельзя бездумно заменить на `if ... else`?**
   Потому что на некоторых шагах могут измениться **обе** координаты (диагональное движение). Если использовать `else if`, то при выполнении первого условия второе будет пропущено, и мы потеряем диагональный шаг.

5. **На каких входных данных вы обязательно проверили программу?**
   - Горизонтальный отрезок: (2, 5) -> (20, 5)
   - Вертикальный отрезок: (7, 2) -> (7, 20)
   - Отрезок справа налево: (20, 8) -> (2, 3)
   - Отрезок снизу вверх: (5, 20) -> (15, 2)
   - Крутой наклон: (3, 2) -> (7, 25)
   - Одна точка: (10, 10) -> (10, 10)

6. **Совпали ли наборы пикселей ЦДА и Брезенхема во всех ваших примерах?**
   В большинстве случаев наборы пикселей совпадают. Однако на некоторых отрезках могут быть небольшие расхождения (на 1 пиксель) из-за разного подхода к округлению. ЦДА округляет математическое значение, а Брезенхем принимает решение на основе накопленной ошибки.
