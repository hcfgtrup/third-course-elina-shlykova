# Практическая работа 1. Растровая графика, пиксели и алгоритм ЦДА

1. **Что такое растеризация?**
   Это процесс преобразования геометрического объекта (например, отрезка или треугольника) в набор пикселей (точек растра) для отображения на экране.

2. **Зачем в ЦДА выбирается `max(|dx|, |dy|)`?**
   Это количество шагов. Выбирается максимальное изменение по одной из осей, чтобы при дроблении шага на каждом шаге не потерять ни одного пикселя. Если выбрать меньшее значение, линия будет иметь разрывы.

3. **Почему координаты приходится округлять?**
   Потому что экран состоит из дискретных пикселей (целочисленных координат), а математические вычисления приращений дают дробные значения (вещественные числа).

4. **Что произойдёт, если начало и конец отрезка совпадают?**
   Алгоритм должен обработать этот случай отдельно (`steps = 0`), иначе произойдёт деление на ноль. В этом случае нужно просто закрасить одну точку.

5. **Какие недостатки ЦДА вы заметили?**
   - Использование вещественных чисел (чисел с плавающей точкой).
   - Операция деления на каждом шаге (или перед циклом).
   - Необходимость округления, что может приводить к накоплению погрешности.
   - Алгоритм не такой эффективный, как, например, алгоритм Брезенхема, который работает с целыми числами.
