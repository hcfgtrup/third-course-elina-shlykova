# Лабораторная работа №5 — Заполнение областей (Flood Fill & Scanline Fill)

## Как запустить
Открыть `index.html` в браузере (через Live Server в VS Code или любой локальный сервер).

## Как задаётся многоугольник
Многоугольник задан вручную в виде массива вершин `polygon` в файле `app.js`. Он содержит 12 вершин и является невыпуклым (в форме сложной фигуры с вырезами).

## Как хранится логический растр
Логический растр хранится отдельно от Canvas в виде двумерного массива `grid` размером 40x30.
- `0` — пустая клетка;
- `1` — граница (контур);
- `2` — залитая клетка.
Canvas только отображает текущее состояние этого массива.

## Связность Flood Fill
Используется 4-связность (соседи сверху, снизу, слева и справа). Для обхода используется стек (Stack), чтобы избежать переполнения стека вызовов.

## Правило обработки вершин в Scanline
Используется правило `yMin <= y < yMax`. Нижняя граница включается, а верхняя — нет. Горизонтальные рёбра полностью пропускаются, чтобы избежать двойного подсчёта.

## Результаты обязательных тестов
1. Прямоугольник: заливается корректно.
2. Треугольник: заливается корректно.
3. Невыпуклый многоугольник: заливается корректно.
4. Горизонтальное ребро: не вызывает ошибок.
5. Строка через вершину: обрабатывается корректно.
6. Flood Fill со стартом внутри: заливает внутреннюю область.
7. Flood Fill со стартом снаружи: заливает внешнюю область.
8. Незамкнутый контур: Flood Fill «вытекает» наружу и заливает всё свободное пространство.

## Сравнение методов
| Метод | Нужна стартовая точка | Использует список вершин | Что обходится |
|---|---|---|---|
| Flood Fill | Да | Нет | Соседние пиксели |
| Scanline | Нет | Да | Строки и рёбра |

## Выводы
- **Flood Fill** требует начальную точку (seed) и работает как поиск по связной области.
- **Scanline Fill** не требует начальной точки, использует геометрию многоугольника и заполняет область построчно.
- При разрыве контура Flood Fill «вытекает» наружу.
- Результаты на границе зависят от правил округления (`Math.ceil` и `Math.floor`).
