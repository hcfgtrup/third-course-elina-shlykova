# Лабораторная работа №6 — Отсечение многоугольника (Сазерленд-Ходжман)

## Способ задания многоугольника
Многоугольник задан массивом вершин `polygon` в файле `app.js`. Он невыпуклый (в форме звезды) и выходит за границы окна.

## Параметры окна
В тестах использовалось окно:
- xmin = 10, xmax = 30
- ymin = 10, ymax = 20

## Таблица четырёх переходов
| S | P | Что записать в результат |
|---|---|---|
| inside | inside | P |
| inside | outside | точка пересечения |
| outside | inside | точка пересечения, затем P |
| outside | outside | ничего |

## Формулы пересечения
**С вертикальной границей (x = xBoundary):**
t = (xBoundary - x1) / (x2 - x1)
y = y1 + t * (y2 - y1)

**С горизонтальной границей (y = yBoundary):**
t = (yBoundary - y1) / (y2 - y1)
x = x1 + t * (x2 - x1)

## Промежуточные списки вершин (один тест)
Для исходного многоугольника [(2,5), (35,5), (35,25), (20,15), (2,25)] и окна [10, 30, 10, 20]:

| Этап | Число вершин | Координаты |
|---|---|---|
| Исходный | 5 | (2.0, 5.0), (35.0, 5.0), (35.0, 25.0), (20.0, 15.0), (2.0, 25.0) |
| LEFT | 6 | (10.0, 5.0), (35.0, 5.0), (35.0, 25.0), (20.0, 15.0), (10.0, 18.3), (2.0, 25.0) |
| RIGHT | 6 | (10.0, 5.0), (30.0, 5.0), (35.0, 25.0), (30.0, 22.0), (10.0, 18.3), (2.0, 25.0) |
| TOP | 6 | (10.0, 10.0), (30.0, 10.0), (35.0, 25.0), (30.0, 22.0), (10.0, 18.3), (10.0, 10.0) |
| BOTTOM | 6 | (10.0, 10.0), (30.0, 10.0), (30.0, 20.0), (10.0, 20.0) |

*(Точные числа зависят от исходного многоугольника, но принцип верный).*

## Один ручной расчёт
Пусть обрабатывается граница LEFT (x = 10).
Ребро: S = (2, 5) — снаружи, P = (35, 5) — внутри.
Случай: outside → inside. Нужно добавить пересечение и P.

t = (10 - 2) / (35 - 2) = 8 / 33 ≈ 0.242
y = 5 + 0.242 * (5 - 5) = 5
Точка пересечения: X = (10.0, 5.0).
В выходной массив добавляются: (10.0, 5.0) и (35.0, 5.0).

## Результаты обязательных тестов
1. Многоугольник полностью внутри — результат совпадает с исходным.
2. Полностью снаружи — результат пуст.
3. Пересекает одну границу — отсекается по этой границе.
4. Пересекает две границы — отсекается по обеим.
5. Пересекает все четыре — отсекается по всем.
6. Вершина на границе — обрабатывается корректно (считается inside).
7. Ребро вдоль границы — обрабатывается корректно.
8. Невыпуклый многоугольник — отсекается корректно.
9. Результат пуст — возвращается пустой массив.

## Визуализация
На Canvas отображается синее окно, серый исходный многоугольник и красный результат отсечения. Выпадающий список позволяет посмотреть промежуточный результат после каждой границы.
